
# Slay the Princess — Scroll to Tell

## Project Overview

This project is a single-page scrolling website based on the game **Slay the Princess**.

The goal of the website is to retell selected parts of the game's story through scrolling. Instead of using buttons, menus, or traditional page navigation, the user progresses through the story only by scrolling.

As the user scrolls, the website will:

- Change background and character images
- Reveal new dialogue and story text
- Transition between locations
- Introduce different versions of the Princess
- Show the repeating / looping structure of the game
- Use animation and motion to make the story feel interactive

The scroll position acts as the main form of interaction.

---

## Main Concept

The website begins with the player on the path in the woods.

As the user scrolls:

1. The Narrator introduces the mission.
2. The player approaches the cabin.
3. The player enters the basement.
4. The Princess is introduced.
5. Important choices and consequences are shown.
6. The story resets.
7. A different version of the Princess appears.
8. More of the true story is revealed.

The user does not manually choose dialogue options.

Instead, scrolling moves the user through selected storylines from the game.

---

## Interaction Goal

The website should feel similar to reading an interactive visual novel.

The user only needs to:

> **Scroll**

Scrolling controls the progression of the story.

For example:

```text
SCROLL
  ↓
Forest appears

SCROLL
  ↓
Narrator dialogue appears

SCROLL
  ↓
Cabin becomes larger

SCROLL
  ↓
Scene changes to the basement

SCROLL
  ↓
Princess appears

SCROLL
  ↓
Dialogue changes

SCROLL
  ↓
Story reaches a major event

SCROLL
  ↓
Screen fades to black

SCROLL
  ↓
The woods appear again...
```
